## 2. Key Architectural Entry Points

### 1. Frontend Entry Point (`src/main.jsx` & `src/App.jsx`)
* `src/main.jsx` initializes React DOM inside `#root` and loads `src/index.css`.
* `src/App.jsx` wraps the application inside `AuthProvider` and `BrowserRouter`.
* Routes `/` and `/auth` sit outside `AppLayout` to remain completely accessible to public visitors.
* Protected routes (`/dashboard`, `/campus-map`, etc.) reside inside `<Route element={<AppLayout />}>`.

### 2. Backend Entry Point (`server/index.js`)
* Initializes Express, enables CORS, parses JSON, and binds static uploads at `/uploads`.
* Mounts both `/api/v1` and `/api` endpoint prefixes.
* Binds global error handling middleware before starting listener on `PORT` (default 5000).
